# Story Asset Format Spec

本文件定义故事资产的正式尺寸规格。自本文件生效后，后续新增资产必须优先遵守这里的尺寸规则。

---

## 1. 正式规格

### 1.1 人物立绘

人物立绘正式规格改为：

- 比例：`9:16`
- 方向：`竖构图`
- 使用场景：手机端、人物对话、角色展示、剧情立绘
- 视觉要求：宽短高长，便于移动端显示人物全身或半身到大腿段

构图原则：
- 优先保留人物从头到腿部以上的完整纵向信息
- 头顶和下摆都要留安全边距
- 不依赖正方形裁切
- 场景线索可作为背景，但人物必须是主信息

### 1.2 场景 / 势力 / 背景图

场景与势力图正式规格改为：

- 比例：`16:9`
- 方向：`横构图`
- 使用场景：剧情背景、章节 CG 背景、势力展示、地图氛围图
- 视觉要求：宽阔、可承载文本、适配横向叙事空间

构图原则：
- 保留足够负空间供文字 UI 使用
- 场景应当服务人物出入与剧情落点
- 禁止只做纯风景海报而不考虑叙事用途

---

## 2. 旧规格处理

旧规格定义：

- 过去已经生成的大量人物立绘为 `1:1` 正方形
- 过去已经生成的场景 / 势力图大多也是 `1:1` 正方形

处理规则：

1. 旧正方形人物立绘统一视为 `legacy-square`
2. 旧正方形场景 / 势力图统一视为 `legacy-square`
3. 旧资源不立即删除，但不再作为后续正式规格继续扩展
4. 如仍需参考旧资源，可用于：
   - 人物脸模参考
   - 服装语言参考
   - 场景氛围参考
5. 最终实装优先使用新规格资产

## 4. 目录建议

建议后续新增目录以区分正式规格与旧规格：

- `src/assets/story/characters/portraits-legacy-square/`
- `src/assets/story/characters/portraits-9x16/`
- `src/assets/story/concepts/factions-legacy-square/`
- `src/assets/story/concepts/factions-16x9/`
- `src/assets/story/concepts/scenes-legacy-square/`
- `src/assets/story/concepts/scenes-16x9/`

如暂时不迁移旧文件，也应至少在规划文档中标注其为旧规格。

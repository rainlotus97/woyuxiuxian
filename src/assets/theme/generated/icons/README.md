# Generated Icon Family

Runtime icon PNGs belong in `transparent/` and use one of the semantic keys
declared in `src/game/theme/generatedIconAssets.ts`, for example:

- `mountain-v1.png`
- `sect-v1.png`
- `spirit-stone-v1.png`

The repository intentionally does not include placeholder glyphs here. Generate
the family from `image2-icon-family-manifest.json`, remove the matte background,
then copy only validated transparent PNGs into `transparent/`.

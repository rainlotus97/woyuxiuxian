# Theme Layout Spec

本文件约束“可换主题素材”如何生成、如何接入，避免边框错位、文字压边、背景被拉坏。

## 1. 资源类型

只能分成这四类，不要混用：

1. `app backdrop`
   - 用于整页外层背景
   - 可以 `cover`
   - 允许远景山、水、云雾
   - 中央必须留空

2. `panel shell`
   - 用于大卡片、剧情卡、主界块
   - 不能随意 `cover`
   - 只能用于接近设计高宽比的容器
   - 边框装饰必须靠边，中央留净空

3. `button shell`
   - 用于按钮底板
   - 允许横向拉伸，但不能把复杂边框放进中段
   - 两端装饰，中间保持平整

4. `emblem / icon frame`
   - 用于头像底、导航图标底、小徽章
   - 必须是独立小组件，不要拿整张面板裁

## 2. 推荐尺寸

### 页面背景

- 主背景：`1440 x 2560`，比例 `9:16`
- 模块背景：`1440 x 2560`，比例 `9:16`
- 剧情氛围背景：`1440 x 2560`，比例 `9:16`

要求：

- 顶部 `14%` 区域给 HUD
- 底部 `12%` 区域给 tab bar
- 中间 `46%` 区域尽量干净

### 面板壳

- 宽面板：`1536 x 1024`，比例 `3:2`
- 中高卡片：`1024 x 1280`，比例 `4:5`
- 横向故事卡：`1536 x 896`，比例约 `12:7`

要求：

- 四边装饰集中在外圈 `8% - 12%`
- 中央 `60%` 区域不要放重纹样
- 不允许做假分栏线，除非该组件固定就是双栏

### 按钮壳

- 主按钮：`1536 x 512`
- 次按钮：`1280 x 448`

要求：

- 左右端有装饰，中段纯净
- 文本安全区高度至少 `44%`
- 不允许在按钮中央烤金纹、宝石、云纹团

### 图标底 / 徽章

- 小徽章：`256 x 256`
- 导航底：`320 x 320`

## 3. 接入规则

### 可以 `background-size: cover` 的

- `app backdrop`
- 远景氛围图

### 不该 `cover` 的

- `panel shell`
- `button shell`
- `icon frame`

这些要么：

- 按固定比例使用
- 要么做成独立装饰层
- 要么拆成代码组件分别控制圆角、描边、投影，图片只负责局部纹理

## 4. 当前项目建议

### 主界大卡

- `GameSurface` 不再默认吃整张面板壳
- 大卡由代码控制圆角、描边、阴影
- 主题图只用于少数“主视觉块”

### 故事卡 / 事件卡

- 可以使用 `panel shell`
- 但卡片高度需要受控
- 移动端优先单列，避免双列压缩

### 挂机列表 / 设置列表

- 使用轻量白底卡
- 不再使用重装饰边框图

## 5. 生图提示词约束

后续生成主题素材时，必须写清楚：

- `no text`
- `clean center area`
- `ornament only near edges`
- `safe area for dynamic UI`
- `not a full screenshot`
- `reusable shell asset`

如果是按钮，还要补：

- `flat readable center`
- `ornament concentrated at ends`

如果是面板，还要补：

- `no central divider`
- `no border distortion`
- `works for dynamic text blocks`
